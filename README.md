# 👵 長輩月活動評分與能力指標分析自動化系統

這是一套專門為長照據點、日照中心或社福機構設計的 Python 自動化報表工具。能夠自動解析長輩每週的活動評分紀錄，進行智慧資料清洗、活動分類對照，並自動產出包含「綜合雷達圖」、「各類別獨立分析」、「活動明細」的精美 Excel 報告。

---

## 🛠️ 系統架構與核心模組解析

本專案主要由以下四個核心模組組成：

1. **智慧擷取與資料清洗模組 (`extract_elder_info_smart`)**
   - **原理**：自動掃描 Excel 工作表的前 15 列與 18 欄，利用正規表達式（`re`）與關鍵字比對，智慧抓取長輩姓名、CMS（長照失能等級）與評估月份，即使原始表格格式有些微位移也能正確識別。
   - **活動清洗**：透過 `clean_act_name` 濾除活動名稱中的括弧與輔助註記（例如將「手作(紙黏土)」正規化為「手作」）。

2. **活動分類與對照庫建立 (`build_category_mapping`)**
   - **原理**：讀取外部的「活動清單」Excel，將各項活動對應至五大核心指標：
     - 手部(大肢體)、手部(精細)、下肢、上下肢全身、認知。
   - **容錯機制**：若遇到未在對照表內的活動，系統會自動進行關鍵字模糊比對，避免漏掉未對應的項目。

3. **月度評分與指標解析 (`process_monthly_scores`)**
   - **原理**：迴圈走訪所有週次工作表，動態定位日期、上下午活動名稱與五大指標（參與度、自我功能、情緒控制力、與他人互動、肢體表現）。
   - **統計計算**：計算各類別的平均分數與參與場次，並自動追加計算「全月總平均」資料列。

4. **進階 Excel 報表與雷達圖產出 (`export_excel_report`)**
   - **原理**：運用 `openpyxl` 建立美觀且排版嚴謹的活頁簿，包含四大工作表：
     - **總表與綜合分析**：內嵌全月能力指標總平均綜合分析雷達圖（範圍固定 1.0 ~ 5.0）。
     - **各類別獨立分析**：為五大核心類型分別繪製獨立雷達圖，並在端點自動標註「指標名稱與分數」。
     - **全月活動明細**：完整保留每一場活動的原始評分紀錄。
     - **活動分類標準庫**：對照清單供查閱。
